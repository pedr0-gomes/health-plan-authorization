1. A primeira etapa consiste na definição e apresentação do sistema que será 
desenvolvido. Para isso, deverão ser apresentados os seguintes 
tópicos: 
• Objetivo e cenário detalhado do sistema escolhido; 
• Principais funcionalidades do sistema a serem implementadas. 
Observação: o sistema proposto deve ser validado e aprovado. 
2. A segunda etapa consiste na implementação do sistema definido. Deve conter 
os seguintes requisitos: 
a) Descrição da modelagem do sistema definido pelo grupo. Para isso, devem 
usar os seguintes diagramas de UML: 
• Diagrama de caso de uso; 
• Diagrama de classe. 
b) Implementação do sistema definido. É necessário que seja abordado na 
implementação dos seguintes conteúdos : 
• Encapsulamento (modificadores de acesso); 
• Construtores; 
• Herança; 
• Polimorfismo (sobrecarga e sobrescrita de métodos); 
• Classes abstratas; 
• Interface; 
• Arrays e/ou Collections; 
• Tratamento de exceções. 
Observação: todas as funcionalidades propostas necessárias deverão ser 
implementadas. Não há problema aplicar outros conceitos, além desses selecionados, caso necessário.
3. A terceira etapa consiste na entrega, validação e apresentação prática do 
sistema desenvolvido. Para isso, deverão: 
a) Enviar a documentação completa do sistema (conforme modelo em anexo) e 
o projeto implementado. 
b) Realizar uma apresentação clara e objetiva sobre o sistema desenvolvido, 
abordando os seguintes tópicos:  
• Explique o problema que o sistema resolve e sua utilidade; 
• Informe o que foi implementado da proposta inicial, destaque novidades 
• Apresente a estrutura do sistema desenvolvido, utilizando como exemplo 
a ilustração abaixo. Destaque todas as classes, interfaces, classes 
abstratas, herança e relacionamentos;
• Apresentação breve do diagrama de casos de uso; 
• Demonstração prática do sistema, utilizando cadastros previamente 
inseridos para agilizar a apresentação.
